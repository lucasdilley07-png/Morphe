# Morphe Full App Audit — July 2026

Four-track audit (core workout, social/engagement, UI system, progress/personalization)
at commit `8c4a72c`, benchmarked against Hevy, Strong, Strava, Whoop, Fitbod, Ladder,
MacroFactor. Every finding cites the file it lives in. House rule respected: all
recommendations are deterministic — no fake AI.

## Verdict in one paragraph

Morphe's foundations are unusually strong — an honest-engineering data layer most
competitors don't have, a best-in-class live co-training layer (Train Together), a real
differentiator in Form Check, a schedule-aware streak smarter than Strava's, and a
distinctive telemetry-HUD visual identity. What's missing is **loop closure**: the app
computes PRs but never celebrates them, computes progression but hides RPE entry,
builds a Live Activity rest timer but doesn't auto-start it, scores leaderboards no
signed-in user can see, and runs a feed that nothing auto-populates. The daily-return
loop for a solo real-account user currently does not exist. Closing those loops is
mostly plumbing — the hard parts are already built.

---

## What's already best-in-class (the moat — don't rebuild)

- **Form Check** — on-device camera pose/rep counting; none of the four big trackers ship it.
- **Train Together live sync** — real-time roster, ready flags, nudges, cross-device
  workout rebuild (`Core/WorkoutParty.swift`). Strongest real social feature in the app.
- **Schedule-aware streak** (`MorpheStore.swift:10409`) — rest days don't break it.
- **Rest-timer Live Activity + Dynamic Island** — wall-clock accurate, full presentation set.
- **Honest engagement primitives** — server-counted reactions, forge-proof verification,
  atomic usernames, tolerant decodes, empty states that name their unlock condition.
- **Progression engine** (`suggestedWorkingWeight`/`progressionNote`,
  `MorpheStore.swift:4738`) — real, deterministic, cites its signal.
- **Unit-correct weight storage**; lb→kg switches never corrupt history.
- **Sound/haptic design** — semantic synthesized sounds, `.ambient` so it never
  interrupts a playlist.

## TIER 1 — Close the loops (highest retention ROI, mostly existing plumbing)

1. **Auto-share completed workouts to the feed** (opt-out per session).
   `logWorkout()` deliberately posts nothing (`MorpheStore.swift:5274`);
   `publishToRealFeed` already accepts `workoutName`. A feed nothing populates stays
   empty forever — Strava/Hevy feeds are ~100% auto-populated.
2. **Celebrate PRs at log time.** PR logic exists (`recentPersonalRecords`,
   `MorpheStore.swift:2987`) but every session gets the same "+50 XP". Diff top sets
   against prior bests inside `logWorkout()` and fire "New PR — Bench 185, +5 lb".
   Highest-emotion moment in a strength app, currently dropped.
3. **Auto-start rest timer on set completion, seeded from per-exercise `restSeconds`.**
   Timer is manual and hardcoded 180s (`WorkoutView.swift:228`); catalog rest data is
   shown but never used live. Activates the Live Activity you already built.
4. **Inline RPE chips in the logging console.** The progression engine feeds on RPE but
   entering it takes 3+ taps through the More sheet (`WorkoutView.swift:4242`).
5. **Local streak-at-risk notification.** The only notification in the app is the
   appointment reminder (`MorpheStore.swift:7044`) — reuse that
   `UNCalendarNotificationTrigger` pattern to fire on evenings when the schedule-aware
   streak is unfulfilled. No backend needed. Duolingo's whole retention model.

## TIER 2 — Structural social (the daily loop for solo users)

6. **Follow graph + username search.** Today the only real relationship is
   coach↔claimed-client; the feed is a global firehose (`CloudBackup.swift:533`).
   `users/{uid}/following/{uid}` + a directory lookup (uniqueness already guaranteed)
   → rank feed by follows. Precondition for buddy pushes and party invites.
7. **Rich workout cards on the feed.** `FeedPost` carries only text + workoutName;
   add duration/sets/volume/PR flags (all one hop away in the session data) and render
   a real card — Hevy's entire feed identity.
8. **Comments** (`posts/{id}/comments/`, same one-doc-per-uid honesty model as
   reactions) and 3–4 reaction types instead of the single heart. Comments create the
   reply-obligation loop that builds relationships.
9. **Surface leaderboards/challenges in the real feed** — currently the discovery card
   is demo-only (`ChatView.swift:47`); signed-in users never see the board they're
   scored on. Add Monday "new week" + Sunday "final standings" moments.
10. **Party recap → shared feed post** tagging co-participants. Today the recap
    evaporates (`WorkoutView.swift:3178`). This is the Strava-group-activity viral moment.

## TIER 3 — Trust & ecosystem

11. **HealthKit write of finished workouts** (`HKWorkout` in
    `finishTrackedWorkoutSession`). Zero HealthKit in the app today — no Activity-ring
    credit. Low effort, huge credibility. Then: HealthKit *read* (sleep/HRV) to
    auto-seed the recovery check-in instead of manual sliders.
12. **Back up `bodyWeightHistory` to cloud + add data export (CSV/JSON).** The weight
    trend lives only in UserDefaults (`MorpheStore.swift:2413`) — a reinstall wipes it.
    No export anywhere.
13. **e1RM chart toggle + rep-PR detection** (Epley, pure arithmetic). Raw top-set
    charts render 185×5 → 185×8 as a flat line (`MorpheStore.swift:2920`).
14. **Plateau detection** — flag exercises with no improvement across N≥3 sessions;
    the delta is already computed (`exerciseStrengthProgress`).
15. **Home/lock-screen widgets** — widget bundle contains only the Live Activity.
    Today's-workout + streak home widget; weekly-volume accessory widget.
16. **Muscle-group balance chart** — needs `muscleGroup` added to `LoggedExercise`
    (optional field, tolerant decode unaffected) before any "am I neglecting legs" view
    is possible.

## TIER 4 — Launch blocker (before strangers share a feed)

17. **Report / block / moderation.** Confirmed zero blocking, reporting, or muting
    anywhere; the real feed is public free-text up to 1000 chars. App Store
    Guideline 1.2 requires flag + block + filter for UGC apps — this gates public
    launch regardless of everything above. Ship: report action → `reports/`
    collection, block list filtered in `fetchRecent`, basic server-side text check.

## TIER 5 — Polish (perceived quality)

18. **Dynamic Type on the signature monospaced type.** 25 fixed `.system(size:)` fonts,
    0 scaling modifiers — `microLabel()`, section titles, badges, tab icons all stay
    tiny at accessibility sizes. Single biggest quality/a11y gap. Use scaled styles or
    `@ScaledMetric`.
19. **Spacing tokens.** Radius is tokenized; spacing is 100% magic numbers
    (12×226, 8×206, 10×185…). Add `MorpheTheme.Spacing` on a 4pt grid; migrate cards first.
20. **Mid-session flexibility** — add exercise, drag-reorder, one-tap swap (keep the
    6-reason questionnaire as optional "why?"). Store has swap only.
21. **Plate calculator** for barbell lifts (45+25+10 per side). Expected in any
    strength tracker; absent.
22. **Warm-up set generation** — 2-3 tappable ramp sets from `suggestedWorkingWeight`,
    logged as labeled warm-ups.
23. **Per-set notes** — extend the `label` pipeline already threading through
    `completeTrackedSet`.
24. **Body-weight trend smoothing** — 7-reading moving average as primary line.
25. **Recovery history** — daily energy/soreness/mood is captured then discarded
    day-scoped; persist as a series and chart it (Whoop's core loop, data already flowing).
26. **Streak freeze token** + visible "at risk today" state.
27. **iOS affordances** — `.refreshable` on Firestore feeds (only 2 surfaces have it),
    spring on the celebration overlay, `.selection` haptics on chips/tabs, skeleton
    loading via `.redacted`.
28. **Small fixes** — `UIScreen.main.bounds` in `AIAgentMessageRow` (deprecated;
    use `containerRelativeFrame`), adopt-or-delete the never-used `EmptyStateCard`,
    reconcile off-system corner radii (12/16 one-offs), make the accent palette
    reactive instead of a static var, chart time-range picker, onboarding: make gender
    skippable + capture weight so nutrition targets personalize day 0, consider
    trimming the 6-tab bar to 5.

## Suggested sequencing

- **Sprint 1 (loop closure):** items 1–5. Almost all plumbing exists; this is the
  week that changes daily retention.
- **Sprint 2 (social spine):** items 6–10.
- **Sprint 3 (trust):** items 11–14.
- **Before public launch:** item 17 (non-negotiable), plus 18–19 for App Store polish.
- Item 15–16 and Tier 5 slot in as filler between sprints.
