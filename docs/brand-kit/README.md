# Morphe Brand Kit

Generated by `swift Tools/make_brand_assets.swift docs/brand-kit` —
edit the tool, not the PNGs. Ships with the coach content kit
(docs/COACH-KIT.md §9) and feeds the DROP announcements.

## Logos

| File | Use |
|---|---|
| `morphe-mark-gold.png` / `.svg` | The M mark, brand yellow on transparent — default |
| `morphe-mark-white.png` / `.svg` | White on transparent — for photos/dark video |
| `morphe-mark-black.png` | Black on transparent — light surfaces only |
| `morphe-mark-ink-tile.png` | Mark on ink square — avatar-safe tile |
| `morphe-wordmark-gold.png` / `-white.png` | MORPHE wordmark, SF Mono black, tracked |
| `morphe-lockup-ink.png` | Mark + wordmark + TRAIN HONEST on ink — social avatar / header |

Colors: yellow `#FFD600`, ink `#050506`, white. No other brand colors
exist; don't recolor the mark.

## Demo share cards (1080×1920)

`demo-card-session.png` · `demo-card-pr.png` · `demo-card-streak.png` ·
`demo-card-week.png`

These show coaches/press what the in-app story cards look like. Every
one carries a visible **DEMO DATA** chip — the real cards render only
logged facts, and a demo must never pass as one. Do not crop the chip
out; if you need a clean example, share a card from a real account.
