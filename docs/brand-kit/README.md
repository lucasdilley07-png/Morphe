## Demo share cards (1080×1920)

`demo-card-session.png` · `demo-card-pr.png` · `demo-card-streak.png` ·
`demo-card-week.png`

These show coaches/press what the in-app story cards look like. Every
one carries a visible **DEMO DATA** chip — the real cards render only
logged facts, and a demo must never pass as one. Do not crop the chip
out; if you need a clean example, share a card from a real account.
